# Repository instructions

## Purpose
This repository is the official CodeSandbox for learning how to interact with Phantom Wallet.

## Layout
- `src/` contains the React and TypeScript sandbox application.
- `public/` contains static assets.

## Commands
Run commands from the repository root:

- `npm start` starts the development server.
- `npm run build` creates a production build.
- `npm test` runs the React Scripts test suite with jsdom.
- `npm run tsc` runs TypeScript type checking.

## Working in this repository
Keep examples focused on teaching Phantom Wallet interactions and preserve compatibility with the dependency versions declared in `package.json`.
